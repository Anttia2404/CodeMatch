# Design system

## Direction
An understated Vietnamese learning marketplace: the request board is the core product artifact. The memorable element is a compact code-editor illustration that frames learning as guided practice. Everything else stays calm, legible, and useful.

## Tokens
- Cobalt `#3458D4`: primary action and selected navigation.
- Jade `#36A98D`: progress and positive state.
- Ink `#20283A`: primary text.
- Muted slate `#778092`: supporting text.
- Paper `#F7F8FA`: page canvas; white surfaces.
- Rule `#E8EBF0`: structural borders.
- Typography: Manrope for brand/headings; DM Sans for UI and body.
- Radius: 7–12px according to control/surface hierarchy; use borders before shadows.
- Spacing follows a 4px base with 8/12/16/24/32 increments.

## Layout and interaction
Desktop: left-aligned two-column introduction above a vertically stacked request board; search and filters precede results. Mobile: single-column content with collapsible navigation and horizontally scrollable filter controls. Use sentence case, explicit Vietnamese action labels, visible keyboard focus, reduced-motion support, labeled controls, and clear empty states. Avoid fabricated metrics, ratings, and verification claims.
