# User flows

## Target learner flow
Register → describe learning objective, level, skills, format, schedule, budget, and sessions → publish an open request → review developer profiles/proposals → compare applicants → accept one proposal → coordinate learning → leave feedback after completion.

## Target developer flow
Register → create professional profile → browse open requests → submit one active teaching proposal per request → attach CV only if needed/desired → respond to learner → conduct agreed sessions → receive feedback.

## Target moderation flow
Review user reports → inspect relevant content under moderator authorization → take documented moderation action → preserve audit event.

## M0 implementation
The landing/discovery shell demonstrates the intended entry point with clearly marked local examples, search filtering, save interaction, and empty state. Registration, publication, proposals, matching, sessions, and moderation are not implemented in M0.
